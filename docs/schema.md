## Зв'язки

| Таблиця А | Таблиця Б | Тип зв'язку (1:N / M:N / 1:1) | Як зроблено (поле чи таблиця зв'язку) | Чому саме такий (одне речення) |
| :--- | :--- | :--- | :--- | :--- |
| `articles` | `factions` | M:N | Таблиця `article_factions` (`article_id`, `faction_id`) | Одна стаття може описувати події за участі кількох фракцій, і до однієї фракції може належати багато статей всесвіту. |
| `profiles` | `articles` | 1:N | Поле `articles.author_id` → `profiles.id` | Один користувач (співавтор або редактор) може створити багато статей, але кожна стаття має одного основного автора. |
| `articles` | `complaints` | 1:N | Поле `complaints.article_id` → `articles.id` | На одну опубліковану статтю читачі можуть подати кілька скарг, а кожна скарга стосується однієї конкретної статті. |
| `profiles` | `complaints` | 1:N | Поле `complaints.reporter_id` → `profiles.id` | Один користувач може надіслати кілька скарг на різні матеріали, а кожна скарга має одного автора звернення. |

### Видалені поля

| Таблиця | Поле | Чому, на мою думку, модель його додала |
| :--- | :--- | :--- |
| `profiles` | `avatar_url` | Модель за шаблоном соціальних мереж додає поле аватара в таблицю профілів, хоча в карті екранів `screens.md` показується лише текстове ім'я автора. |
| `profiles` | `created_at` | Модель автоматично додає службову часову позначку створення запису в кожну таблицю за загальною практикою проєктування БД. |
| `factions` | `created_at` | Модель додала часову позначку створення фракції за звичкою, хоча картка фракції на `/factions` показує лише назву, колір, опис і кількість статей. |
| `articles` | `views_count` | Модель додала лічильник переглядів як типову функцію для вікі-платформ «на майбутнє», якої немає у специфікації MVP. |
| `articles` | `updated_at` | Модель додала час останньої зміни статті, орієнтуючись на відкладену функцію історії ревізій із `feature-plan.md`, яка не входить у MVP. |
| `complaints` | `moderator_comment` | Модель припустила, що модератор залишає текстове пояснення при закритті скарги, але на екрані `/moderation` дія виконується однією кнопкою. |
