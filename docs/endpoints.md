# Точки доступу

| № | Метод | Шлях | Сторінка або дія | Вхідні дані (з обмеженнями) | Вихідні дані | Коди помилок | Хто має право | Екран |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Т1 | GET | / | HomePage; listPublishedArticles, listFactions | category — необов'язкове (персонаж, локація, подія, артефакт); factionId — необов'язкове (UUID); query — необов'язкове (до 100 символів) | 200, список опублікованих статей і фракцій | 401 | Будь-який авторизований користувач (гість, співавтор, редактор) — лише опубліковані статті | Головна (Каталог статей) |
| Т2 | GET | /articles/[id] | ArticlePage; getArticle | id — обов'язкове, UUID статті | 200, дані статті, мітки фракцій та ілюстрація | 401, 404 | Усі авторизовані — опубліковану статтю; співавтор — власну статтю; редактор — будь-яку статтю | Перегляд статті |
| Т3 | POST | /articles/[id] | returnToDraftAction | articleId — обов'язкове, UUID статті | 200, статтю переведено у статус «чернетка» | 400, 401, 404 | Співавтор — лише власну статтю; головний редактор — будь-яку статтю | Перегляд статті |
| Т4 | POST | /articles/[id] | submitComplaintAction | articleId — обов'язкове, UUID; reason — обов'язкове, 5–500 символів | 201, id створеної скарги | 400, 401, 403, 404 | Співавтор або головний редактор — на опубліковану статтю | Перегляд статті |
| Т5 | GET | /editor | EditorPage; getArticle, listFactions | id — необов'язкове, UUID чернетки для редагування | 200, дані чернетки та перелік фракцій | 401, 404 | Співавтор (власна чернетка) або головний редактор | Редактор чернетки |
| Т6 | POST | /editor | saveDraftAction | id — необов'язкове (UUID); title — обов'язкове, 3–120 символів; category — обов'язкове (персонаж, локація, подія, артефакт); content — обов'язкове, 10–10000 символів; status — чернетка або на перевірці; factionIds — масив UUID | 201 (нова) або 200 (оновлена), id статті | 400, 401, 403, 404 | Лише співавтор або головний редактор (оновлення — лише власної статті або редактором) | Редактор чернетки |
| Т7 | POST | /editor | deleteArticleAction | id — обов'язкове, UUID статті | 200 | 400, 401, 404 | Співавтор — лише власну статтю; головний редактор — будь-яку статтю | Редактор чернетки |
| Т8 | GET | /factions | FactionsPage; listFactions | — | 200, список фракцій із кількістю прив'язаних статей | 401 | Будь-який авторизований користувач (гість, співавтор, редактор) | Довідник фракцій |
| Т9 | POST | /factions | createFactionAction | name — обов'язкове, 2–80 символів; colorHex — обов'язкове, формат #RRGGBB; description — обов'язкове, 5–500 символів | 201, id нової фракції | 400, 401, 403 | Лише головний редактор (role = 'редактор') | Довідник фракцій |
| Т10 | POST | /factions | deleteFactionAction | factionId — обов'язкове, UUID фракції | 200 | 400, 401, 403, 404 | Лише головний редактор (role = 'редактор') | Довідник фракцій |
| Т11 | GET | /moderation | ModerationPage; listModerationQueue, listComplaints | — | 200, список статей «на перевірці» та відкритих скарг | 401, 403 | Лише головний редактор (role = 'редактор') | Панель модерації |
| Т12 | POST | /moderation | moderateArticleAction | articleId — обов'язкове, UUID; decision — обов'язкове (опубліковано або чернетка) | 200 | 400, 401, 403, 404 | Лише головний редактор (role = 'редактор') | Панель модерації |
| Т13 | POST | /moderation | resolveComplaintAction | complaintId — обов'язкове, UUID; decision — обов'язкове (вирішено або відхилено) | 200 | 400, 401, 403, 404 | Лише головний редактор (role = 'редактор') | Панель модерації |
